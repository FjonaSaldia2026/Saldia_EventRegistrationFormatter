# Python Programming Activities

Author: Fjona Saldia  
Programming Language: Python

 Project Description
This repository contains my Python programming activities. These activities demonstrate the use of lists, array indexing, functions, searching, computations, updating values, string manipulation, and date formatting.

 Activities

 Activity 1: Build and Display Your Data
- Created a list containing five items.
- Accessed each element using indexing.
- Displayed elements using their index positions.
- Demonstrated that Python indexing starts at 0.

 Activity 2: Data Analysis Mini App
- Created a Student Score Analyzer.
- Displayed and searched student scores.
- Computed the average score.
- Updated scores using indexing.
- Used functions and a menu-driven interface.

 Activity 3: Student Information Formatter
- Collected the student's first name, last name, section, and favorite subject.
- Formatted names using string methods.
- Displayed the full name in proper case and uppercase.
- Counted the characters in the full name.

 Activity 4: Deadline and Date Formatter
- Collected an event title and date.
- Used Python's datetime library.
- Displayed the date in a readable format.
- Identified the month and weekday.

Activity 5: Student Event Registration Formatter
- Collected student information and event details.
- Cleaned and formatted text inputs.
- Displayed the student's full name and section.
- Formatted the event date using datetime.

Python Concepts and Features Used

Lists and Indexing
- Creating lists
- Accessing elements through indexes
- Traversing list elements
- Searching and updating values

Functions and Control Structures
- Defining and calling functions
- For loops and while loops
- If-else statements
- Menu-driven programs

String Methods
- `strip()` – removes extra spaces.
- `title()` – capitalizes the first letter of each word.
- `upper()` – converts text into uppercase.
- `len()` – counts characters.

Date and Time
- `datetime` – Python date and time module.
- `date()` – creates a date.
- `strftime()` – formats dates into readable text.
