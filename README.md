 Student Event Registration Formatter

 Description
This program collects student information and event details. It cleans and formats the text inputs and displays the event date in a clear and readable format.

 Language Used
Python

 String Feature Used
- `strip()` – removes extra spaces.
- `title()` – capitalizes the first letter of each word.
- `upper()` – converts text into uppercase.

 Date/Time Feature Used
- `datetime` – used to work with dates.
- `date()` – creates a valid event date.
- `strftime()` – formats the date into a readable format.

 Version History
- **Version 1:** Basic input and output.
- **Version 2:** Added string formatting.
- **Version 3:** Added date formatting.

 Sample Output

```text
Student Event Registration Summary

Name: Juan Dela Cruz
Name Code: JUAN DELA CRUZ
Section: MAGNESIUM
Event: Science Fair
Event Date: June 3, 2026
Language Used: Python

Date/Time Feature Used: datetime

Registration record created successfully.
```
